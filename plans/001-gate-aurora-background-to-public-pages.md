## Problem

`ClientLayout.tsx` wraps every single route in the app — including the entire
`/admin/**` panel, `/login`, and `/register` — and unconditionally renders a
decorative "aurora" background of three permanently-animating blurred blobs.
This background is invisible on admin pages (painted behind the opaque admin
UI) but still costs a continuous `filter: blur(140px)` composite + transform
animation on every single frame, forever, on every page load — including
pages where a recruiter/client will never see it and where the admin user
(you) spends the most repeated, session-long time.

Current code, `frontend/src/components/ClientLayout.tsx:29-44`:

```tsx
export default function ClientLayout({ children }: { children: React.ReactNode }) {
  const cursorRef = useRef<HTMLDivElement>(null);
  const followerRef = useRef<HTMLDivElement>(null);
  const pathname = usePathname();
  // The persistent 3D scene belongs only to the home page — it's driven by
  // the hero/skills scroll anchors, which don't exist on /login, /admin,
  // /blog, or /projects. Rendering it elsewhere left it stuck at full
  // opacity, painting over those pages' content.
  const isHome = pathname === "/";
  // The chatbot belongs to the public-facing portfolio only — not the admin
  // panel or its auth pages, where it would be noise at best.
  const isPublicPage =
    !pathname?.startsWith("/admin") && pathname !== "/login" && pathname !== "/register";
```
