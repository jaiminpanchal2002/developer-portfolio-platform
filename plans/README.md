## Execution order

All 13 were independent and have now all been applied. One deviation from
plan 010's literal text during execution: `admin/jobs/page.tsx`'s
`scaleX: job.matchScore / 100` required a `?? 0` fallback
(`(job.matchScore ?? 0) / 100`) to satisfy TypeScript — the original
`width` template string silently tolerated `undefined`, but dividing does
not.
